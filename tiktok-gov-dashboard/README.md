# TikTok Live Governance

Admin dashboard for monitoring and moderating TikTok Live streams. Built from a Figma Make design.

## Stack

- Vite 6 + React 18 + TypeScript
- Tailwind CSS v4 (`@tailwindcss/vite`)
- shadcn/ui (Radix primitives + CVA)
- React Router v7
- Recharts

## Getting started

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Routes

- `/` — Dashboard
- `/live-streams` — Live stream monitor
- `/users` — User management
- `/analytics` — Platform analytics
- `/violations` — Violation queue
- `/settings` — Moderation settings
